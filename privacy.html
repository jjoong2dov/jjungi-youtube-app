개인정보처리방침 (Privacy Policy)

시행일: 2026-11-09

Jjungi Channel Manager는 채널 운영자 본인만 사용하는 개인용 도구입니다.

  1. 수집하는 정보: 운영자 본인의 YouTube 채널 정보, 동영상 정보, 댓글, YouTube 분석 수치. YouTube API 서비스를 통해서만 가져옵니다.
  2. 이용 목적: 운영자 본인 채널의 업로드·정보 수정·댓글 관리·성과 분석.
  3. 보관: 인증 토큰과 분석 결과는 운영자 개인 서버에만 저장되며 제3자에게 제공·판매하지 않습니다.
  4. 권한 철회: Google 계정 권한 페이지에서 언제든 접근을 철회할 수 있습니다.
  5. 이 도구는 YouTube API 서비스를 사용합니다. YouTube 서비스 약관, Google 개인정보처리방침이 함께 적용됩니다.

This private tool uses YouTube API Services only to manage the owner's own channel. Data is stored only on the owner's server and is never shared or sold. Access can be revoked at https://myaccount.google.com/permissions. See the YouTube Terms of Service and Google Privacy Policy.
